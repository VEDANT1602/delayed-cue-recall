# Analysis plan for a fresh-seed check
Written before calculating outcomes on seeds 1000–1023.

The reference training code and six-dimensional inputs follow commit 686f4f7e50229f061b4efdc5cb5d3f4812a2fc48 of VEDANT1602/delayed-cue-recall. The original comparison of artificially generated corridors selected an early checkpoint after inspecting a later ceiling. Here the only primary endpoint is change in percentage of correct choices, next-texture minus choice alone, at 60 updates and 16 held-out texture steps, for auxiliary weight 0.5. The unit is a paired training seed. Use 24 consecutive unexamined seed identifiers (1000–1023). Retain ties, give each seed equal weight, and report the mean and two-sided 95% percentile bootstrap interval across pairs (20,000 draws, random seed 902491). A negative value favors choice only. The interval describes variability under the specified seed and path generation process; it does not establish a claim across architectures or tasks.
 
Two secondary checks use the same trajectories, test paths, initialization, update count and loss implementation. Change the auxiliary weight to 0.125 or 2.0. These are descriptive weight checks. Exactly balanced cue erasure, all 1,024 test trials accounted for, and successful CSV verification of the original archive are integrity checks. No replacement seeds or parameter changes after examining performance.
