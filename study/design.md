# Analysis choices before the new fits (local record)

The previous published 24-pair, update-60 test remains the only publicly prospectively registered claim. This local plan is for the new time-course experiments. It is not an OSF registration.

**Main question.** Does fixed positive weight on predicting a distracting sequence increase the number of optimizer updates needed to recover a preceding binary cue? Compare shared recurrent encoder trained on terminal cue only with one also predicting the next observation. Matched random initial state, split, data streams and optimizer within each pair. Leave previous seeds and checkpoints separate.

**Corridor.** 20 fresh training seed pairs (5100–5119) per tanh, GRU and LSTM, all with 12 hidden units. Train on delays 2, 4 and 8; evaluate delays 8, 16 and 32 every 10 updates through 200 on fixed independent cue-balanced paths. Primary endpoint for each architecture: first second consecutive scheduled visit with at least 90 percent cue accuracy at delay 16. A run without an event by update 200 is right censored. Compute restricted mean time through update 200, absolute paired difference, seed-paired percentile bootstrap 95% intervals; give uncertainty only across training seeds. Alternative accuracies 80 and 95 percent, delay 32, zeroed cue control. A smaller horizon or a low event count cannot prove that models never learn.

**Measured distractors.** Independent training seeds 6500–6511 per architecture. Feed the terminal decision task with measured three-axis acceleration from the UCI HAR archive; place a synthetic independent cue before each snippet, pair each physical snippet with both cues, and predict future standardized acceleration on valid observed transitions. Training participants and evaluation participants are disjoint. As above, train short delays, evaluate 8, 16, 32, keep the time limit 200 and threshold 90 percent. The auxiliary loss uses weight 0.5 times mean squared error; the categorical corridor uses weight 0.5 times cross-entropy. Compare signs and uncertainty within each task. The tasks' loss scales differ. Interpret measured recordings, artificial cue intervention and real human behaviors separately.

**Natural HAR.** A separate six-activity benchmark with nine inertial axes from the same UCI release. Four held-out subjects from the 21-person official training partition form a validation group; the official nine-person test set is inspected only for the model chosen by validation macro-F1. Use four new initialization seeds, 35 epochs each in the fixed and control condition, GRU width 48, box-averaged nonoverlapping groups of four raw samples, minibatches of 128, Adam at 0.002; mean-pool recurrent states for the activity head. Match batches, show validation learning curves and test macro-F1, accuracy, subject-level results. Compare a train-standardized multinomial logistic regression on window summaries. This estimates a different endpoint than cue recall.

**Measured activity memory stress test (exploratory addendum, written before its own fits).** To make the measured comparison address retention directly, use an original human activity label as the target for a 16-reading prefix, then append an unrelated measured 16-reading distractor. Prefix and suffix come from the same fold, from the nine inertial channels. In each matched group, give the same suffix to six distinct target activities, so a suffix-only decoder is exactly chance. Supply the prefix/distractor phase as a tenth channel. The GRU is read only at the terminal state. Train for 1,500 updates, with 12 paired training seeds (seed range 8800–8811), 36 examples/update, Adam 0.002, width 48, clipping at 1 and auxiliary next-sample MSE weight 0.5 on the distractor alone. Record validation accuracy every 50 updates; sustained 75 percent means two consecutive validation visits at/above 75 percent. Use a fixed balanced validation panel and separate fixed balanced test panel of 128 suffix groups each. At the fixed horizon report test accuracy and prefix-erasure control for every seed. Treat inability to attain the threshold as censored. No OSF or prospective public registration is claimed for this addition.
